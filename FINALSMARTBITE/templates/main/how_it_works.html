Under the hood

How SmartBite actually works

No magic, no dummy numbers, just your data flowing through a few clear steps.

1

Register

Your profile (age, height, weight, daily budget) is saved once, hashed password included.

2

Calculate

Nutrition targets are computed in Python and logged to MySQL every time you run the calculator.

3

Track

Expenses you add are aggregated in SQL, monthly totals and category splits, no manual maths.

4

Ask

SmartBite AI builds a context object from your own rows, then answers, using the OpenAI API for open-ended reasoning and plain Python for anything the database can already answer exactly.

Why some answers skip the AI entirely

"How much have I spent this month?" doesn't need a language model, it needs one SQL query. SmartBite calculates totals, remaining budget and targets directly in Python/SQL, and only calls the OpenAI API for natural conversation, meal planning reasoning and open-ended questions. That keeps answers to data questions exact and instant.

What happens if the AI service is unavailable

If the OpenAI API fails or times out, SmartBite falls back to its own rule-based engine for budget, protein, calorie and basic meal questions, so the app never shows an error or a blank reply.
